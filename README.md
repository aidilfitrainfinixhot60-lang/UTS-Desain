 📁 Struktur Folder
📄 Penjelasan File
- **index.html** → Halaman utama tampilan website.
- **style.css** → Mengatur tampilan layout, warna, posisi, margin, dan seluruh style.
- **script.js** → Berisi fungsi interaktif seperti menu, button, dan lainnya.
- **images/** → Menyimpan gambar yang digunakan pada halaman.

- Menerapkan konsep penataan layout (flexbox, grid, padding, margin).
- Menerapkan desain yang rapi dan responsif sesuai instruksi tugas.
